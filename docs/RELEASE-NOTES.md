## 压缩包套压缩包，也能一层层点进去

修一个挺影响手感的问题：**预览窗口里的嵌套压缩包双击没反应**。现在双击外层包里的 `inner.zip`、`7z`、`tar.gz`，会直接再开一个预览窗口继续往下点，不用先解压到桌面。

### 修复

- **双击预览窗口里的嵌套压缩包没有任何反应**。原因有点绕：本程序自己是 zip/tar/rar/7z 的默认打开方式，双击内层包时系统把打开事件路由回正在运行的本实例，而旧逻辑用「一个进程只处理一个包」的门槛把它整个吞掉了。现在改成多窗口 —— 每次收到打开事件都新开一个预览窗口
- **缓存清理改成按窗口进行**。以前关掉任意一个窗口就会把整个预览缓存清空，多窗口下会误伤其它窗口；现在关窗只清自己的那份。内层包打开前会先复制到独立缓存目录，所以即使外层窗口先关掉，内层预览也照样能用。最后一个窗口关闭或退出时仍然全清，不留垃圾
- **同一个包不会重复开窗**。已经开着预览窗口时再双击同一个包，直接把窗口调到前面
- 窗口标题改成「包名 — 压缩包预览器」，开了多个窗口时一眼能分清

### 下载

| 文件 | 说明 |
|---|---|
| **`ArchivePreview-<版本>.dmg`** | 推荐。打开后把「压缩包预览器」拖到 Applications 文件夹 |
| `ArchivePreview-<版本>.zip` | 备用。解压后把 `压缩包预览器.app` 拖进「应用程序」 |

两个包都是**通用二进制**，Apple Silicon 和 Intel Mac 都能直接跑，无需 Rosetta。

因为是本地临时签名（ad-hoc），首次打开需要**右键点图标 → 打开 → 再点「打开」**，之后双击就正常了。这是没做 Apple 开发者公证的必然结果。

### 升级方式

已经装过旧版的，把新的 `压缩包预览器.app` 拖进「应用程序」覆盖即可；默认打开方式沿用之前的设置，不用重新登记。从源码装的直接 `./install.sh`。

### 系统要求

macOS 13 或更新。无第三方依赖 —— rar / 7z / 加密 zip 的解码都复用系统自带的 libarchive。
