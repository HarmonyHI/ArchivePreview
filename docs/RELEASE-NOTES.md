## 双击就能看，看完再决定要不要解

这个版本的压缩包预览器支持**在列表里直接双击文件**打开它 —— 只解出这一个文件到缓存，用系统默认程序打开，不必先把整个包解开。

### 新增

- **双击打开单个文件**：双击列表里的文件 → 只解压这一项到缓存 → 用默认程序打开；双击文件夹则是展开 / 折叠
- 同一个文件第二次双击命中缓存，不重复解压
- 双击 `.app` / `.pkg` / `.command` 这类可执行内容时**不会自动运行**，只在访达中选中，避免误触

### 修复

- **文件名含 `[ ] * ?` 时定向解压失败**。libarchive 把成员名当作 glob pattern，`报告[2024].txt` 会被当成字符类。现在统一做通配符转义
- **解压选中文件夹时冒出无关的空目录**。之前预建了全部目录条目，现在只建所选项目的父目录链

### 下载

| 文件 | 说明 |
|---|---|
| **`ArchivePreview-<版本>.dmg`** | 推荐。打开后把「压缩包预览器」拖到 Applications 文件夹 |
| `ArchivePreview-<版本>.zip` | 备用。解压后把 `压缩包预览器.app` 拖进「应用程序」 |

两个包都是**通用二进制**，Apple Silicon 和 Intel Mac 都能直接跑，无需 Rosetta。

因为是本地临时签名（ad-hoc），首次打开需要**右键点图标 → 打开 → 再点「打开」**，之后双击就正常了。这是没做 Apple 开发者公证的必然结果。

### 系统要求

macOS 13 或更新。无第三方依赖 —— rar / 7z 的解码复用系统自带的 libarchive。

安装后可以在应用的「设置」里一键接管 zip / tar / rar / 7z 等 8 种格式的双击行为，也可以随时还原给系统「归档实用工具」。
